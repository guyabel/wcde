# Past population sizes for all countries by education

A data set containing population sizes for all countries by education
between 1950 and 2020 from Version 3.

## Usage

``` r
past_epop
```

## Format

A data frame with 574,968 rows and 7 variables, including:

- name:

  Area name

- country_code:

  ISO 3 digit country code

- year:

  Year of observation from 1950 to 2020 in five-year steps

- age:

  Five-year age groups

- education:

  Education group

- sex:

  Sex

- epop:

  Population size in thousands for each age, sex and education group
